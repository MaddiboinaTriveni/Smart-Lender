# 💰 Smart-Lender

A secure and intelligent loan management web application that enables users to apply for loans, track loan status, and manage lending operations efficiently. The project follows the complete Software Development Life Cycle (SDLC), including brainstorming, requirement analysis, design, development, testing, documentation, and demonstration.

# 📌 Project Overview

Smart-Lender is a web-based loan management system designed to simplify the lending process through a secure and user-friendly interface. The application enables users to submit loan requests, monitor application status, and manage loan information efficiently.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/MaddiboinaTriveni/Smart-Lender.git
```

### Open Project

```bash
cd Smart-Lender
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run

```bash
python app.py
```
